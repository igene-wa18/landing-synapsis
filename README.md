# Synapsis Landing Page

This is the landing page for **Synapsis**, a modern connection and communication platform. 

## Overview
The landing page is designed with a sleek, modern aesthetic featuring:
- Responsive design
- Dark mode support
- Interactive UI elements (mockup chats, floating badges)
- Smooth animations and transitions

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS with custom properties for theming)
- Google Fonts (Onest, Plus Jakarta Sans)

## File Structure
- `index.html`: The main HTML file containing the structure, styles, and logic for the landing page.

## How to Run
Simply open `index.html` in any modern web browser to view the landing page. No build process or server is required.
